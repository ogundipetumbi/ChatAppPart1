# ChatApp Part 1

A Java-based chat application project developed as part of my Software Development coursework.

## About the Project

This project focuses on the user registration and login components of a chat application.

The project helped me practise Java programming, input validation, user registration and login functionality.

## Features

- User registration
- Username validation
- Password complexity validation
- Cellphone number validation
- User login
- Login status handling

## Technologies

- Java
- NetBeans
- Maven
- JUnit
